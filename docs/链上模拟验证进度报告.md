## 🎯 测试策略

### 当前方法

我们采用**指令构造验证**策略，因为:

1. **测试账户限制**: 使用随机生成的 Keypair，其 ATA 不存在
2. **主要目标**: 验证指令构造的正确性，而非真实执行
3. **框架验证**: 证明模拟框架工作流程正常

### 测试输出示例

```
✅ 步骤 1: 获取 Pool 状态 - 成功
✅ 步骤 2: 本地计算 - 完成
✅ 步骤 3: 构造指令 - 成功
⚠️  步骤 4: 模拟执行 - 失败（预期的）
   原因：AccountNotFound
   分析：测试账户不存在，这是正常的
✅ 结论：指令构造验证成功
```

### 完整测试（可选）

如需完整测试（真实执行）:
1. 使用 `docs/id.json` 中的真实账户
2. 确保账户有足够的余额
3. ATA 可能需要预先创建

## 🔧 技术细节

### 参数结构对比

#### CLMM
```rust
pub struct RaydiumClmmParams {
    pub pool_state: Pubkey,        // Pool 地址
    pub amm_config: Pubkey,
    pub token0_mint: Pubkey,
    pub token1_mint: Pubkey,
    pub token0_vault: Pubkey,
    pub token1_vault: Pubkey,
    pub observation_state: Pubkey,
    pub token0_decimals: u8,
    pub token1_decimals: u8,
    pub token0_program: Pubkey,
    pub token1_program: Pubkey,
}
```

#### AMM V4
```rust
pub struct RaydiumAmmV4Params {
    pub amm: Pubkey,           // AMM pool 地址
    pub coin_mint: Pubkey,     // Base token
    pub pc_mint: Pubkey,       // Quote token
    pub token_coin: Pubkey,    // Pool's coin token account
    pub token_pc: Pubkey,      // Pool's pc token account
    pub coin_reserve: u64,     // Coin reserve amount
    pub pc_reserve: u64,       // PC reserve amount
}
```

### 本地计算方法

#### CLMM
- 使用完整的 tick-by-tick 遍历算法
- 考虑多个 tick arrays
- 使用 Raydium 官方数学库
- **函数**: `calculate_swap_amount_with_tick_arrays()`

#### AMM V4 / CPMM
- 使用恒定乘积公式: `x * y = k`
- 输出 = `(input_with_fee * output_reserve) / (input_reserve + input_with_fee)`
- 考虑手续费（通常 0.25% = 25 basis points）
- **函数**: 手动实现
