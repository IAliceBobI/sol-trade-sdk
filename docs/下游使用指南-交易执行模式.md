# 下游使用指南 - 交易执行模式 API

## 📚 概述

Sol Trade SDK 现在支持三种交易执行模式，可以根据不同场景灵活选择：

1. **LocalCalculation** - 本地计算（快速估算）
2. **Simulation** - 链上模拟（准确验证）
3. **RealExecution** - 真实执行（实际交易）

---

## 🚀 快速开始

### 1. 基本用法

```rust
use sol_trade_sdk::{
    TradingClient, TradeBuyParams, TradeTokenType,
    trading::ExecutionMode,
    DexType,
};
use solana_sdk::{pubkey::Pubkey};
use std::sync::Arc;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 创建客户端
    let rpc_url = "http://127.0.0.1:8899";
    let payer = Arc::new(Keypair::new());
    let config = TradeConfig::new(
        rpc_url.to_string(),
        HashMap::new(),
        CommitmentConfig::confirmed(),
    );

    let client = TradingClient::new(payer, config).await?;

    let jup_mint = Pubkey::from_str("JUPyiwrYJFskUPiHa7hkeR8VUtAeFoSYbKedZNsDvCN")?;

    // ========================================
    // 场景 1: UI 价格显示（本地计算）
    // ========================================
    let estimate = client.buy(TradeBuyParams {
        dex_type: DexType::RaydiumClmm,
        input_token_type: TradeTokenType::SOL,
        mint: jup_mint,
        input_token_amount: 100_000_000, // 0.1 SOL
        slippage_basis_points: Some(100), // 1%
        ..Default::default()
    }).await?;

    println!("预估获得: {} JUP", estimate.amount_out);

    // ========================================
    // 场景 2: 交易前验证（链上模拟）
    // ========================================
    let validation = client.buy(TradeBuyParams {
        dex_type: DexType::RaydiumClmm,
        input_token_type: TradeTokenType::SOL,
        mint: jup_mint,
        input_token_amount: 100_000_000,
        slippage_basis_points: Some(100),
        simulate: true,  // ⭐ 开启模拟模式
        wait_transaction_confirmed: false,
        ..Default::default()
    }).await?;

    if validation.success {
        println!("✅ 模拟成功，预计获得: {} JUP", validation.amount_out);
    }

    // ========================================
    // 场景 3: 真实执行
    // ========================================
    let trade = client.buy(TradeBuyParams {
        dex_type: DexType::RaydiumClmm,
        input_token_type: TradeTokenType::SOL,
        mint: jup_mint,
        input_token_amount: 100_000_000,
        slippage_basis_points: Some(100),
        simulate: false, // ⭐ 关闭模拟，真实执行
        wait_transaction_confirmed: true,
        ..Default::default()
    }).await?;

    if let Some(sig) = trade.signatures.first() {
        println!("✅ 交易成功: {}", sig);
    }

    Ok(())
}
```

## 📊 三种模式对比

| 模式 | 速度 | 准确性 | 费用 | 适用场景 |
|------|------|--------|------|---------|
| **LocalCalculation** | ⚡️ < 10ms | ±1% | 无 | 价格查询、UI 显示、批量查询 |
| **Simulation** | 🐢 1-2s | 100% | 无 | 交易验证、测试、滑点确认 |
| **RealExecution** | 🐌 2-5s | 100% | 有 | 正式交易、改变状态 |

## 💡 使用场景指南

### 场景 1: 实时价格显示

**需求**: UI 显示"用 0.1 SOL 买 JUP，能得到多少？"

**解决方案**: 使用本地计算（无需 RPC 调用，极快响应）

```rust
// 方案 A: 使用 quote_exact_in
use sol_trade_sdk::instruction::utils::raydium_clmm::quote_exact_in;

let result = quote_exact_in(
    &rpc,
    &pool_address,
    100_000_000, // 0.1 SOL
    false,      // zero_for_one
).await?;

println!("预估获得: {} JUP (耗时: < 10ms)", result.amount_out);
```

### 场景 2: 批量路径查询

**需求**: 查询多个 DEX 的价格，找出最优路径

**解决方案**: 并发使用本地计算

```rust
use futures::future::join_all;

let dex_pools = vec![
    raydium_clmm_pool,
    raydium_cpmm_pool,
    orca_whirlpool_pool,
];

let futures = dex_pools.into_iter().map(|pool| {
    quote_exact_in(&rpc, &pool, 100_000_000, false)
});

let results = join_all(futures).await?;

// 找出最优路径
let best = results.iter()
    .max_by_key(|r| r.amount_out)
    .unwrap();

println!("最优 DEX: {:?}, 输出: {}", best.dex, best.amount_out);
```

### 场景 3: 交易前验证

**需求**: 用户点击"确认交易"前，验证交易是否成功

**解决方案**: 使用模拟模式

```rust
let validation = client.buy(TradeBuyParams {
    simulate: true,  // ⭐ 关键：开启模拟
    slippage_basis_points: Some(100),
    ..Default::default()
}).await?;

if !validation.success {
    println!("⚠️  模拟失败: {:?}", validation.error);
    return Err("交易可能失败".into());
}

println!("✅ 模拟成功，可以执行");
```

### 场景 4: 完整交易流程（最佳实践）

**推荐流程**: 三阶段交易

```rust
// 阶段 1: 快速显示价格（本地计算）
let estimate = calculate_price_locally(&pool, 100_000_000)?;
println!("预估获得: {} JUP", estimate);

// 阶段 2: 用户点击"预览"后，模拟验证
let validation = simulate_transaction(&pool, 100_000_000)?;
if !validation.success {
    println!("⚠️  警告: 模拟失败");
    // 提示用户调整滑点
}

// 阶段段 3: 用户点击"确认"后，真实执行
let trade = execute_real_transaction(&pool, 100_000_000)?;
println!("✅ 交易成功: {}", trade.signature);
```

## 🔧 API 参考

### ExecutionMode 枚举

```rust
pub enum ExecutionMode {
    LocalCalculation,  // 本地计算
    Simulation,       // 链上模拟
    RealExecution,    // 真实执行
}
```

**方法**:
- `is_local_calculation()` - 是否为本地计算
- `is_simulation()` - 是否为模拟
- `is_real_execution()` - 是否为真实执行
- `description()` - 获取模式描述
- `speed_level()` - 获取速度等级 (1-3)
- `accuracy_level()` - 获取准确性等级 (1-3)

### TradingClient 参数

```rust
pub struct TradeBuyParams {
    pub dex_type: DexType,
    pub input_token_type: TradeTokenType,
    pub mint: Pubkey,
    pub input_token_amount: u64,
    pub slippage_basis_points: Option<u16>,
    pub simulate: bool,  // ⭐ 关键：true=模拟，false=真实执行
    pub wait_transaction_confirmed: bool,
    // ...
}
```

**关键字段**:
- `simulate` - 控制执行模式
  - `true` - 模拟模式
  - `false` - 真实执行

### 完整的三阶段交易示例

```rust
use sol_trade_sdk::{TradingClient, TradeBuyParams, TradeTokenType, DexType};
use solana_sdk::Keypair;

async fn complete_trading_flow() -> Result<(), Box<dyn std::error::Error>> {

    let jup_mint = Pubkey::from_str("JUPyiwrYJFskUPiHa7hkeR8VUtAeFoSYbKedZNsDvCN")?;

    // 阶段 1: 快速估算（本地计算）
    println!("🔍 计算价格...");
    // 显示在 UI 上
```

## 🎯 性能优化建议

### 1. UI 响应优化

```rust
// ❌ 不好：每次价格变化都调用 RPC
async fn on_amount_changed(amount: u64) -> u64 {
    // RPC 调用，延迟 100ms+
    calculate_price_with_rpc(amount).await
}

// ✅ 好：使用本地计算
async fn on_amount_changed(amount: u64) -> u64 {
    // 本地计算，< 10ms
    calculate_price_locally(amount)
}
```

### 2. 批量查询优化

```rust
// ❌ 不好：串行查询 RPC
async fn batch_query() {
    for pool in pools {
        let price = simulate_transaction(pool).await; // 1-2s 每个
    }
    // 总耗时: 10-20s
}

// ✅ 好：并发本地计算
async fn batch_query() {
    let futures = pools.into_iter().map(|pool| {
        calculate_price_locally(pool) // < 10ms 每个
    });

    let results = join_all(futures).await;
    // 总耗时: ~100ms
}
```

### 3. 缓存策略

```rust
use std::time::Duration;
use tokio::time::Instant;

// 缓存价格计算结果（避免重复计算）
struct PriceCache {
    prices: HashMap<(Pubkey, Pubkey), (u64, Instant)>,
    ttl: Duration,
}

impl PriceCache {
    async fn get_or_calculate(&mut self, pool: &Pubkey, mint: &Pubkey) -> u64 {
        let key = (*pool, *mint);

        if let Some((price, timestamp)) = self.prices.get(&key) {
            if timestamp.elapsed() < self.ttl {
                return *price; // 缓存未过期
            }
        }

        // 缓存过期，重新计算
        let price = calculate_price_locally(pool, mint).await;
        self.prices.insert(key, (price, Instant::now()));
        price
    }
}
```

## ⚠️ 注意事项

### 1. 本地计算的准确性

- 本地计算通常有 ±1% 的误差
- 原因：Pool 状态可能已更新，链上价格已变化
- **建议**：
  - 显示时标注"预估"或"约"
  - 交易前务必使用模拟验证

### 2. 模拟模式的限制

- 模拟不会改变链上状态
- 但某些交易可能仍会失败（如余额不足）
- **建议**：
  - 模拟成功后，尽快执行真实交易
  - 设置适当的滑点（建议 1-3%）

### 3. 真实执行的风险

- 交易可能失败（滑点、网络延迟等）
- 会消耗真实费用
- **建议**：
  - 交易前使用模拟验证
  - 设置合理的滑点保护
  - 监控交易状态
