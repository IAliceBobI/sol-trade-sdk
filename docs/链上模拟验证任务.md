# 链上模拟验证任务文档

## 📋 任务概述

### 目标
为每个 DEX 协议实现**本地计算 vs 链上模拟**对比验证，确保离线计算的准确性。

### 背景
当前的验证测试（如 `verify_clmm_calculation.rs`）存在严重问题：
- 本地计算调用 `calculate_swap_amount_with_tick_arrays()`
- RPC Quote 调用的也是同一个函数
- **这是"本地计算 vs 本地计算"，没有真正验证链上执行结果**

### 正确的验证方式
```
本地计算（离线数学）  vs  链上模拟（真实交易执行）
        ↓                           ↓
    使用数学公式               构造真实 Swap 指令
    计算输出金额               → RPC 模拟执行
        ↓                           ↓
        └─────────── 对比 ──────────┘
                    ↓
            验证准确性（误差 < 1%）
```

## 🔄 通用实现流程（适用于所有 DEX）

每个 DEX 的测试都需要遵循以下流程：

### 步骤 1：获取 Pool 状态
```rust
let pool_state = get_pool_by_address(&rpc, &pool_address).await?;
```

### 步骤 2：本地计算
```rust
let local_output = calculate_swap_amount(
    amount_in,
    pool_state,
    // ... 其他参数
)?;
```

### 步骤 3：构造真实交易指令
```rust
let instruction_builder = get_instruction_builder(dex_type);
let instructions = instruction_builder.build_buy_instructions(&params).await?;
```

### 步骤 4：链上模拟执行
```rust
let simulation_result = simulate_swap_transaction(
    &rpc,
    &payer,
    instructions,
    input_token_account,
    output_token_account,
    input_mint,
    output_mint,
).await?;
```

### 步骤 5：解析模拟结果
```rust
let simulated_output = simulation_result.actual_output_amount;
```

### 步骤 6：对比验证
```rust
let diff = (local_output as i64 - simulated_output as i64).abs();
let error_rate = (diff as f64 / simulated_output as f64) * 100.0;

assert!(error_rate < 1.0, "误差过大: {}%", error_rate);
```

## 📝 注意事项

1. **账户初始化**：测试账户不需要真实余额，但相关的 ATA 可能需要预先创建
2. **Pool 状态**：确保 Pool 地址有效且可访问
3. **Compute Units**：注意 CU 限制，可能需要在测试中设置更高的限制
4. **串行测试**：所有测试都应使用 `#[serial_test::serial]` 避免冲突
5. **日志解析**：当前的日志解析可能不够准确，需要根据实际日志格式调整
